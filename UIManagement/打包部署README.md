## 🚀 快速开始

### 第一步：打包客户端程序
```cmd
双击运行：打包客户端.bat
```

**等待 2-5 分钟**，打包完成后会在 `dist/` 目录生成部署文件。

### 第二步：查看打包结果
```
UIManagement/dist/
├── PermissionClient.exe         # 主程序
├── config.json                  # 配置文件
├── 启动客户端.bat               # 启动脚本
├── 配置服务器地址.bat           # 配置工具
├── 创建桌面快捷方式.vbs         # 快捷方式工具
├── 部署说明.txt                 # 简要说明
├── 快速开始.md                  # 快速指南
├── 客户端部署指南.md            # 详细指南
└── 客户端部署清单.md            # 部署清单
```

### 第三步：部署到客户端电脑

1. **复制文件**：将 `dist` 文件夹复制到客户端电脑 `C:\PermissionClient\`

2. **启动程序**：双击 `PermissionClient.exe`

3. **验证连接**：查看程序顶部状态栏，应显示"✓ 已连接到服务器"

4. **创建快捷方式**（可选）：双击 `创建桌面快捷方式.vbs`

## 🐛 常见问题

### Q: 打包失败
A: 确保已安装所有依赖：
```cmd
pip install -r requirements.txt
pip install pyinstaller
```

### Q: 打包文件太大
A: 这是正常的，包含了 PyQt5 库（约50-80MB）

### Q: 客户端无法连接服务器
A: 
1. 确保服务器 192.168.110.77:5000 正常运行
2. 测试网络：`ping 192.168.110.77`
3. 浏览器测试：http://192.168.110.77:5000/health
4. 检查 config.json 配置

### Q: 需要修改服务器地址
A: 编辑 `config.json`：
```json
{
  "server": {
    "host": "新服务器IP",
    "port": 5000
  }
}
```

## 📊 批量部署

### 部署多个客户端

1. **准备部署包**
   ```cmd
   打包一次，可部署到所有客户端
   ```

2. **分发方式**
   - 网络共享
   - U盘复制
   - 远程桌面部署

3. **统一配置**
   - 所有客户端使用相同 config.json
   - 统一安装路径便于管理

### 批量部署脚本示例

```batch
@echo off
echo 批量部署客户端...
for %%i in (PC1 PC2 PC3) do (
    echo 正在部署到 %%i...
    xcopy /E /I /Y dist \\%%i\C$\PermissionClient\
)
echo 批量部署完成！
pause
```
