# 🚀 客户端打包与部署 - 快速开始

## 一、立即开始打包

### 在当前开发机器上执行：

```cmd
1. 进入 UIManagement 目录
cd E:\Project\PermissionManagementSys\UIManagement

2. 双击运行
打包客户端.bat
```

**打包时间：** 约 2-5 分钟

## 二、打包完成后

查看输出目录：
```
UIManagement/dist/
```

包含以下文件：
```
✅ PermissionClient.exe          - 主程序（约 50-80MB）
✅ config.json                   - 配置文件
✅ 启动客户端.bat                - 启动脚本
✅ 配置服务器地址.bat            - 配置工具
✅ 创建桌面快捷方式.vbs          - 快捷方式工具
✅ 部署说明.txt                  - 简要说明
```

## 三、部署到客户端电脑

### 3.1 复制文件

将 `UIManagement/dist/` 文件夹复制到每台客户端电脑：
```
推荐路径: C:\PermissionClient\
```

### 3.2 在客户端电脑执行

#### 步骤1：测试连接
双击 `PermissionClient.exe`

#### 步骤2：验证连接
查看程序顶部状态栏：
- ✅ **"✓ 已连接到: 斯能服务器管理系统"** - 连接成功
- ❌ **"✗ 未连接到服务器"** - 连接失败

如果连接失败，检查：
1. 服务器 192.168.110.77 是否正常运行
2. 网络是否连通：`ping 192.168.110.77`
3. 浏览器测试：http://192.168.110.77:5000/health

#### 步骤3：创建快捷方式（可选）
双击 `创建桌面快捷方式.vbs`

桌面会自动创建"斯能服务器管理系统"快捷方式。

## 五、批量部署

### 5.1 网络共享方式

**在服务器上：**
```cmd
1. 共享 dist 文件夹
2. 设置共享权限为"读取"
```

**在客户端上：**
```cmd
1. 打开 \\server\share\dist
2. 复制整个文件夹到 C:\PermissionClient\
3. 运行 PermissionClient.exe
```

### 5.2 U盘分发方式

```cmd
1. 将 dist 文件夹复制到U盘
2. 在每台客户端复制到 C:\PermissionClient\
3. 运行程序
```

### 5.3 批量部署脚本

创建 `批量部署.bat`：
```batch
@echo off
echo 正在部署客户端...
xcopy /E /I /Y "\\192.168.110.77\share\dist" "C:\PermissionClient\"
echo 部署完成！
echo.
echo 是否立即启动程序？(Y/N)
set /p choice=
if /i "%choice%"=="Y" (
    cd C:\PermissionClient
    start PermissionClient.exe
)
```

## 七、故障排除

### 问题1: 无法连接服务器

**现象：** 状态栏显示"未连接到服务器"

**解决步骤：**
```cmd
1. 测试网络
ping 192.168.110.77

2. 测试服务器
浏览器打开: http://192.168.110.77:5000/health

3. 检查配置
打开 config.json，确认服务器地址正确

4. 检查防火墙
暂时关闭客户端防火墙测试
```

### 问题2: 程序无法启动

**现象：** 双击程序无反应或闪退

**解决步骤：**
```cmd
1. 检查文件
确认 PermissionClient.exe 和 config.json 都存在

2. 命令行运行查看错误
cd C:\PermissionClient
PermissionClient.exe

3. 重新复制
从打包文件夹重新复制 dist 文件夹

4. 安装运行库
安装 Visual C++ Redistributable
```

### 问题3: 端口被占用或阻止

**解决方案：**
```cmd
1. 检查端口
telnet 192.168.110.77 5000

2. 如果 telnet 不可用，先启用
dism /online /Enable-Feature /FeatureName:TelnetClient

3. 检查防火墙规则
4. 联系网络管理员
```

## 十、配置文件说明

### config.json 关键配置

```json
{
  "system_name": "斯能服务器管理系统",  // 系统名称
  "server": {
    "host": "192.168.110.77",          // ⭐ 服务器IP
    "port": 5000                        // ⭐ 服务器端口
  },
  "default_directory": "D:\\存放资料",  // 默认目录
  "user_mapping": {                     // 用户映射
    "username": "全名"
  }
}
```

**需要修改的配置：**
- ⭐ `server.host` - 如果服务器IP不是 192.168.110.77
- ⭐ `server.port` - 如果服务器端口不是 5000

修改后保存并重启客户端程序。
