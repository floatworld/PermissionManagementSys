# 📦 服务器打包部署文件说明

本目录包含将服务器程序打包并部署到 **192.168.110.77** 所需的所有文件。

## 📂 文件清单

### 核心程序文件
- `start_server.py` - 服务器启动脚本（源代码）
- `api.py` - API 路由
- `database.py` - 数据库管理
- `services.py` - 业务逻辑
- `dao.py` - 数据访问层
- `file_monitor.py` - 文件监控

### 打包工具
- `build_server.py` ⭐ - **打包脚本（核心）**
- `打包服务器.bat` ⭐ - **一键打包工具**

### 部署文件
- `PermissionServer_Startup.xml` - 任务计划配置
- `设置开机自启动.bat` - 自启动设置工具

### 文档
- `快速开始.md` ⭐ - **快速部署指南（推荐先看）**
- `服务器部署指南.md` - 详细部署文档
- `部署清单.md` - 部署检查清单
- `README.md` - 本文档

## 🚀 快速开始

### 第一步：打包

```cmd
双击运行：打包服务器.bat
```

打包完成后在 `dist/` 目录下生成可执行文件。

### 第二步：部署

1. 将 `dist/` 文件夹复制到目标服务器 `C:\PermissionServer\`
2. 在目标服务器上运行部署步骤（见下文）

### 第三步：详细步骤

请查看 **`快速开始.md`** 获取详细的部署步骤。

## 🐛 常见问题

### Q: 打包失败
A: 确保已安装所有依赖：`pip install -r requirements.txt`

### Q: 打包文件太大
A: 这是正常的，包含了所有依赖库（约30-50MB）

### Q: 目标服务器无法运行
A: 
1. 确保以管理员权限运行
2. 检查是否缺少 Visual C++ Redistributable
3. 查看是否有防火墙阻止
