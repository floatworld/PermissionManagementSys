## 🚀 部署到 192.168.110.77

### 步骤1: 复制文件
- [ ] 将 `dist` 文件夹复制到目标服务器
- [ ] 重命名为 `C:\PermissionServer\`

### 步骤2: 配置防火墙
在目标服务器上执行：
```cmd
netsh advfirewall firewall add rule name="PermissionServer" dir=in action=allow protocol=TCP localport=5000
```

### 步骤3: 测试运行
- [ ] 双击 `启动服务器.bat`
- [ ] 检查是否以管理员权限运行
- [ ] 访问 http://localhost:5000/health 验证

### 步骤4: 设置开机自启动
- [ ] 确认程序路径为 `C:\PermissionServer\`
- [ ] 如路径不同，编辑 `PermissionServer_Startup.xml`
- [ ] 右键管理员运行 `设置开机自启动.bat`
- [ ] 验证任务计划创建成功

### 步骤5: 重启验证
- [ ] 重启服务器
- [ ] 检查服务是否自动启动
- [ ] 从客户端访问 http://192.168.110.77:5000/health

## 🔧 管理命令速查

### 服务控制
```cmd
# 立即启动
schtasks /run /tn "PermissionServer"

# 停止服务
taskkill /f /im PermissionServer.exe

# 查看状态
tasklist | findstr PermissionServer
```

### 任务计划
```cmd
# 查看任务
schtasks /query /tn "PermissionServer"

# 删除任务
schtasks /delete /tn "PermissionServer" /f
```

### 防火墙
```cmd
# 查看规则
netsh advfirewall firewall show rule name="PermissionServer"

# 删除规则
netsh advfirewall firewall delete rule name="PermissionServer"
```

## 📞 故障排除

### 问题1: 服务无法启动
- 确认以管理员权限运行
- 检查端口 5000 是否被占用: `netstat -ano | findstr :5000`
- 查看是否有错误弹窗

### 问题2: 客户端无法连接
- 检查防火墙规则是否添加
- 检查服务是否正在运行
- 使用 `ping 192.168.110.77` 测试网络
- 使用 `telnet 192.168.110.77 5000` 测试端口

### 问题3: 开机不自动启动
- 检查任务计划是否存在
- 确认任务计划中的路径正确
- 检查是否勾选"使用最高权限运行"
- 查看任务计划历史记录

## 📝 配置文件说明

### config.json 关键配置
```json
{
  "system_name": "斯能服务器管理系统",  // 可修改
  "server": {
    "host": "127.0.0.1",
    "port": 5000                         // 可修改端口
  },
  "default_directory": "D:\\存放资料",  // 可修改默认目录
  "user_mapping": {
    // 可添加/删除用户映射
  }
}
```

修改配置后需要重启服务。
