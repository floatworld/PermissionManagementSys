# 🚀 服务器打包与部署 - 快速开始

## 一、立即开始打包

### 在当前开发机器上执行：

```cmd
1. 进入 Server 目录
cd E:\Project\PermissionManagementSys\Server

2. 双击运行
打包服务器.bat
```

**打包时间：** 约 2-5 分钟

## 二、打包完成后

查看输出目录：
```
Server/dist/
```

包含以下文件：
```
✅ PermissionServer.exe          - 主程序（约 30-50MB）
✅ config.json                   - 配置文件
✅ 启动服务器.bat                - 启动脚本
✅ PermissionServer_Startup.xml  - 任务计划配置
✅ 设置开机自启动.bat            - 自启动设置脚本
✅ 部署说明.txt                  - 简要说明
✅ 服务器部署指南.md             - 详细指南
```

## 三、部署到 192.168.110.77

### 3.1 复制文件

将 `Server/dist/` 文件夹复制到目标服务器：
```
目标路径: C:\PermissionServer\
```

### 3.2 在目标服务器执行

#### 步骤1：打开防火墙端口
**以管理员身份运行 PowerShell：**
```cmd
netsh advfirewall firewall add rule name="PermissionServer" dir=in action=allow protocol=TCP localport=5000
```

#### 步骤2：测试运行
双击 `启动服务器.bat`

#### 步骤3：验证服务
打开浏览器访问：
```
http://localhost:5000/health
```

看到以下响应表示成功：
```json
{
  "status": "ok",
  "service": "斯能服务器管理系统",
  "version": "1.0"
}
```

#### 步骤4：设置开机自启动
**右键以管理员身份运行：**
```
设置开机自启动.bat
```

看到"✓ 开机自启动设置成功！"表示完成。

## 五、常用管理命令

```cmd
# 查看服务状态
tasklist | findstr PermissionServer

# 停止服务
taskkill /f /im PermissionServer.exe

# 启动服务（通过任务计划）
schtasks /run /tn "PermissionServer"

# 查看任务计划
schtasks /query /tn "PermissionServer"
```

## 六、如果遇到问题

### 问题：端口被占用
```cmd
# 查看占用端口的进程
netstat -ano | findstr :5000

# 修改 config.json 中的端口号为其他值
```

### 问题：无管理员权限
- 右键 PermissionServer.exe
- 选择"以管理员身份运行"

### 问题：防火墙阻止
```cmd
# 验证防火墙规则
netsh advfirewall firewall show rule name="PermissionServer"

# 如无规则，重新添加
netsh advfirewall firewall add rule name="PermissionServer" dir=in action=allow protocol=TCP localport=5000
```

### 问题：客户端无法连接
1. 确认服务器防火墙已开放 5000 端口
2. 确认服务正在运行
3. 使用 ping 测试网络连通性
4. 使用 telnet 测试端口连通性

## 八、配置修改

### 修改系统名称
编辑 `config.json`：
```json
{
  "system_name": "你的系统名称"
}
```

### 添加用户映射
编辑 `config.json`：
```json
{
  "user_mapping": {
    "username": "全名"
  }
}
```

修改后重启服务生效。
