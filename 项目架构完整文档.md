# 斯能服务器管理系统 - 完整项目架构

## 🎯 项目概述

**系统名称**: 斯能服务器管理系统  
**版本**: 2.0.0  
**架构**: 客户端-服务器 (C/S)  
**开发日期**: 2024年10月  

### 系统目标
1. 提供专业的服务器目录权限管理
2. 实时监控文件系统活动
3. 完整的操作审计日志

## 🗄️ 数据库设计

### users - 用户表
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | INTEGER | PRIMARY KEY | 自增主键 |
| username | TEXT | UNIQUE, NOT NULL | 用户名 |
| role | TEXT | DEFAULT '普通用户' | 角色 |
| created_at | TEXT | | 创建时间 |
| last_login | TEXT | | 最后登录 |
| is_active | INTEGER | DEFAULT 1 | 是否激活 |

### directories - 目录表
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| directory_id | INTEGER | PRIMARY KEY | 自增主键 |
| path | TEXT | UNIQUE, NOT NULL | 目录路径 |
| parent_id | INTEGER | FOREIGN KEY | 父目录ID |
| is_shared | INTEGER | DEFAULT 0 | 是否共享 |
| created_at | TEXT | | 创建时间 |
| last_scanned | TEXT | | 最后扫描 |

### permissions - 权限表
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| permission_id | INTEGER | PRIMARY KEY | 自增主键 |
| user_id | INTEGER | FOREIGN KEY, NOT NULL | 用户ID |
| directory_id | INTEGER | FOREIGN KEY, NOT NULL | 目录ID |
| can_read | INTEGER | DEFAULT 0 | 读权限 |
| can_write | INTEGER | DEFAULT 0 | 写权限 |
| can_delete | INTEGER | DEFAULT 0 | 删除权限 |
| can_execute | INTEGER | DEFAULT 0 | 执行权限 |
| is_recursive | INTEGER | DEFAULT 0 | 递归应用 |
| granted_at | TEXT | | 授予时间 |
| granted_by | TEXT | | 授予人 |
| note | TEXT | | 备注 |

**唯一约束**: (user_id, directory_id)

### audit_log - 审计日志表
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| log_id | INTEGER | PRIMARY KEY | 自增主键 |
| user_id | INTEGER | | 用户ID |
| username | TEXT | | 用户名 |
| directory_id | INTEGER | | 目录ID |
| action_type | TEXT | NOT NULL | 操作类型 |
| file_path | TEXT | | 文件路径 |
| timestamp | TEXT | | 时间戳 |
| ip_address | TEXT | | IP地址 |
| success | INTEGER | DEFAULT 1 | 是否成功 |
| details | TEXT | | 详细信息 |

**索引**:
- idx_audit_timestamp (timestamp)
- idx_audit_user (user_id)
- idx_permissions_user (user_id)
- idx_directories_path (path)

## 🔌 API接口规范

### 基础信息
- **协议**: HTTP/1.1
- **格式**: JSON
- **编码**: UTF-8
- **端口**: 5000

### 响应格式
```json
{
  "success": true,
  "data": { ... },
  "error": "错误信息"
}
```

### 接口列表

#### 健康检查
- `GET /health` - 服务健康检查
- `GET /api/info` - 系统信息

#### 目录管理
- `GET /api/directory/structure` - 获取目录结构
- `POST /api/directory/scan` - 扫描并同步目录
- `POST /api/directory/tree` - 扫描目录树(不存储)

#### 权限管理
- `GET /api/permissions` - 获取所有权限
- `GET /api/permissions/user/<username>` - 获取用户权限
- `POST /api/permissions/directory` - 获取目录权限
- `POST /api/permissions/grant` - 授予权限
- `POST /api/permissions/revoke` - 撤销权限
- `POST /api/permissions/check` - 检查权限

#### 用户管理
- `GET /api/users` - 获取所有用户
- `GET /api/users/<username>` - 获取用户信息
- `POST /api/users` - 创建用户

#### 审计日志
- `GET /api/audit/logs` - 查询审计日志
- `GET /api/audit/user/<username>` - 获取用户活动
- `GET /api/audit/statistics` - 统计信息

## 🔒 安全特性

1. **SQL注入防护**: 所有SQL查询使用参数化语句
2. **路径验证**: 防止目录遍历攻击
3. **审计日志**: 记录所有关键操作
4. **NTFS集成**: 系统级权限控制
5. **CORS限制**: 限制跨域访问源

## 📊 性能优化

1. **数据库索引**: 在高频查询字段建立索引
2. **连接池**: 单例模式管理数据库连接
3. **查询限制**: 大数据量查询默认限制
4. **递归深度**: 目录扫描限制深度
5. **异步处理**: UI使用QThread避免阻塞

## 🚀 部署流程

### 开发环境
```
1. 本地运行服务器: python Server/start_server.py
2. 配置CLIENT: SERVER_URL = "http://127.0.0.1:5000"
3. 运行客户端: python UIManagement/permission_manager.py
```

### 生产环境 (192.168.110.77)
```
1. 拷贝Server目录到192.168.110.77
2. 安装依赖: pip install -r requirements.txt
3. 启动服务: 双击 start.bat 或 python start_server.py
4. 配置客户端: SERVER_URL = "http://192.168.110.77:5000"
5. 启动客户端连接测试
```
